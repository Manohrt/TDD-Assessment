# String Calculator TDD Kata (Ruby)

This is a TDD-based implementation of the String Calculator Kata, built in **Ruby (v3.1.4)** using **RSpec** for testing.

## Requirements

- Ruby '3.1.4'
- rspec '3.13.0'
- Bundler

## Setup Instructions

1. **Clone the Repository**

   git clone https://github.com/your-username/string-calculator-kata.git
   cd string-calculator-kata

2. Install Dependencies
	
	bundle install

3. Initialize RSpec (First Time Only)

	bundle exec rspec --init

4. Running Tests

	- For run all test file:

		bundle exec rspec

	- For run a specific test file 

		bundle exec rspec spec/file_name.rb
